# Spam Message Detection

## Task 02 - Machine Learning Project

This project detects spam and legitimate SMS messages using Python and Machine Learning.

### Technologies Used
- Python
- Pandas
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes

### Features
- Spam message detection
- Model training and testing
- Accuracy evaluation
- Prediction of new messages

### Dataset
UCI SMS Spam Collection:
https://archive.ics.uci.edu/dataset/228/sms+spam+collection

### How to Run
1. Install libraries: `pip install pandas scikit-learn`
2. Run: `python spam_detection.py`
3. Enter a message to get a prediction.
